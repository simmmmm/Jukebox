Help

Most questions are about signing in. Start there.

Signing in

Jukebox asks for the address of your own music server: Jellyfin, Emby, Plex, Navidrome or another Subsonic server. When it says it cannot reach the server, walk through these.

Open the address in a browser first

On the same device, type the address in Safari or your browser. If the server's page does not open there, Jukebox cannot reach it either, and the address or the network is the thing to fix. If it opens, type that same address in Jukebox.

The port

If the address in your browser has a number after a colon, type it too: 192.168.1.10:8096. The usual ones are 8096 for Jellyfin and Emby, 4533 for Navidrome and 32400 for Plex. With no port typed, Jukebox tries the address as it is and then those ports.

http or https

With nothing in front, Jukebox uses http for an address on your home network and https for any other. If yours is the other way round, type it in full: https://music.example.com or http://nas:4533.

Over plain http, anyone on the way can read your password. Use https for a server you reach over the internet.

Behind a reverse proxy

If your server lives under a path, the path is part of the address: https://example.com/jellyfin. Leave off what the web app adds after it, such as /web.

Away from home

An address like 192.168.1.10, nas or nas.local works only on your home network. On mobile data or someone else's Wi-Fi you need the address your server has on the internet, or a VPN to your home.

Tailscale

Turn Tailscale on, on this device, before you sign in. Then use the server's Tailscale address, the one that starts with 100, with its port: 100.101.102.103:8096. Its ts.net name works too once Tailscale serves it over https.

iPhone, iPad and Mac: the local network

The first time, the system asks whether Jukebox may find devices on your local network. Without it, a server at home cannot be reached. Turn it on in Settings, Privacy & Security, Local Network.

Try the demo

Navidrome keeps a public demo server. Address demo.navidrome.org, user name demo, password demo. If that signs in, Jukebox and your connection are fine, and the address of your own server is what to look at.

The password is refused

Then the server was found. Check the user name and password in the server's own web page. Plex signs in at plex.tv: use Sign In with Plex. A server that asks for an API key or token takes that in place of the password.

Last.fm

The radio asks Last.fm which artists and songs sound alike, by name. It works with no Last.fm account. Add your user name under Settings, Radio, and the radio also learns from your scrobbles. Jukebox writes nothing to Last.fm; scrobbling is your server's job.

To turn it off: Settings, Radio, Enhance Radio with Last.fm (Preferences on Linux). The radio then chooses from your library alone.

Downloads

The arrow on an album or a playlist keeps it on the device. Keep Songs I Play, on by default, also keeps what you play often, up to the size you set in Settings, Downloads.

If nothing downloads: the server may not allow downloads for your account (Settings says so), or the songs are waiting for Wi-Fi. Download over Cellular in Settings lets them come over mobile data.

Still stuck?

Open an issue on GitHub. In Jukebox, choose Copy Diagnostic Info (on the sign-in page, in Settings under About, or in the Help menu) and paste it in. It holds the app's version, your system and the kind of server. It never holds your server's address, your user name or a password.
